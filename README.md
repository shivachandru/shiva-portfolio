# Shiva S. — Portfolio

A dark, editorial portfolio site built with React, TypeScript, Vite, GSAP and Lenis.

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository into Vercel. Vercel detects Vite automatically; use `npm run build` and `dist` as the output directory. There are no server routes requiring rewrite configuration.

## Personalizing content

Edit the `services`, `tech`, `projects`, and `process` arrays near the top of `src/App.tsx`. Replace the contact email and social URLs in the contact section. The project artwork is CSS-built placeholder imagery, ready to replace with real screenshots. Connect the contact form to an email or form endpoint before launch; it currently validates entries and shows a local confirmation.

## Accessibility & motion

The site uses semantic sections and form labels, keyboard-accessible links and controls, a mobile navigation toggle, and respects `prefers-reduced-motion`.
